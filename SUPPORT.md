# Suporte

## Onde pedir ajuda

Antes de abrir uma issue:

1. consulte a seção de [solução de problemas](./README.md#solução-de-problemas);
2. confirme os requisitos e execute **Testar ambiente** no Paperclip;
3. procure uma issue aberta ou encerrada com a mesma mensagem de erro;
4. remova credenciais, tokens, prompts e dados de clientes de qualquer log.

Abra uma issue usando o formulário adequado:

- **Bug** para comportamento reproduzível diferente do documentado;
- **Proposta** para uma melhoria ou novo caso de uso;
- **Dúvida** quando a documentação e a busca não resolverem o problema.

Este projeto é mantido pela comunidade e não oferece prazo garantido de
resposta. Informações claras e uma reprodução mínima aumentam a chance de ajuda.

## O que informar

- versão do pacote, do Node.js, do Paperclip e do `agy`;
- sistema operacional e alvo de execução: local, SSH ou sandbox;
- configuração relevante com todos os segredos removidos;
- passos mínimos para reproduzir;
- resultado esperado e resultado observado;
- trecho pequeno do erro já redigido.

## Segurança

Não use issues públicas para vulnerabilidades ou exposição de dados sensíveis.
Siga as instruções de [SECURITY.md](./SECURITY.md).
